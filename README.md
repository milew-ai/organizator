# Organizator

A modular workspace and utility project designed for organization, task management, and structured workflows.

## Project Structure & Documentation
- **[AGENTS.md](AGENTS.md)**: Engineering standards, architectural conventions, and operational workflows for AI coding agents operating in this repository.
- **[git-ssh-setup/SKILL.md](git-ssh-setup/SKILL.md)**: Reusable agent skill for setting up SSH keys, GitHub authentication, and remote URL updates.

## Getting Started & Repository Setup
- **Repository Authentication:** Configured via SSH (`git@github.com:milew-ai/organizator.git`).
- **Workspace Standards:** Follow guidelines specified in `AGENTS.md` for development lifecycle, testing, and git standards.
